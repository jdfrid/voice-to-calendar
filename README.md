# Voice Router

אפליקציה סטטית בעברית שמקבלת הודעה בדיבור או בהקלדה, מזהה אם מדובר בפגישה או במשימה, ומכינה פעולה מתאימה מול Google Calendar או Google Tasks.

## הפעלה

אפשר לפתוח את `index.html` ישירות בדפדפן. לחיבור Google מומלץ להריץ שרת מקומי:

```bash
node server.js
```

ואז לפתוח:

```text
http://127.0.0.1:4173
```

לזיהוי דיבור מומלץ להשתמש ב-Chrome.

## חיבור Google

קישור "פתח ביומן Google" עובד ללא הגדרה נוספת ופותח טיוטת אירוע ביומן.

כדי לאפשר יצירה ישירה של אירועים ומשימות:

1. צור OAuth Client ID ב-Google Cloud Console עבור Web application.
2. אפשר את Google Calendar API ואת Google Tasks API.
3. הוסף את מקור האתר שלך ל-Authorized JavaScript origins.
4. הדבק את ה-Client ID בפאנל ההגדרות באפליקציה ולחץ "התחבר".

## דוגמה

הודעה:

```text
יש לי מחר פגישה אצל רופא השיניים בשעה 1200 ברחוב הרצל 42 תל אביב
```

תזוהה כפגישה ותיצור אירוע בשם "תור לרופא שיניים" למחר בשעה 12:00, עם הכתובת שזוהתה.
